# Field Ops Portfolio

An interactive portfolio of twelve connected applications built to run technology
operations across a portfolio of private properties. Each app turned a manual,
reactive process into something automated and proactive.

Open **`index.html`** to start. It links to a working, in-browser demo of each app:

| App | Group | What it is |
| --- | --- | --- |
| **Beacon** | Operations and monitoring | Always-on infrastructure status wall. Calm when healthy, impossible to miss when something breaks. |
| **Engine** | Operations and monitoring | Monitoring-to-ticketing pipeline. Files and clears tickets automatically, one incident at a time. |
| **Sentinel** | Operations and monitoring | Property intelligence. A newspaper-style brief of permits, landmark filings, weather and regulatory signals around every site. |
| **Field** | Field work | Phone and iPad app for technicians: today's tasks, a vendor directory that works offline, and an asset register with a guided camera that reads equipment data plates. |
| **Recon** | Field work | Guided on-site technology audit that files a structured record. |
| **Horizon** | Field work | Device lifecycle planner that tracks age and end of life across sites and forecasts replacement budgets. **Prototype, not in production.** |
| **Requests** | Client and vendor portals | Client request portal. Ask for anything in a Messages-style thread and follow it to done. |
| **Partners** | Client and vendor portals | Vendor compliance portal. Vendors upload certificates, W-9s and NDAs through one link with email-code sign-in; an AI agent reads each document, extracts terms and dates, and flags gaps. |
| **Vendor** | Client and vendor portals | Vendor scorecards, certificate and license expiry tracking, and head-to-head comparison. |
| **Generator** | Reporting and analytics | Pulls a visit's work and exports a polished, client-ready PDF report. |
| **Scorecard** | Reporting and analytics | Operations dashboard with alert analytics and work-platform adoption boards. |
| **Tempo** | Reporting and analytics | Scores team adoption of the work platform against role benchmarks and auto-coaches. |
| **Admin** | Platform | Admin console: one sign-in across every app and an app-centric access grid for people and roles. |

Also included: **Ambient**, an ideation-stage concept for passive field documentation.

All of the apps share one backbone: the work platform (Asana today) is the system of
record that every app reads from and writes to.

## Notes

- Every demo runs entirely in your browser. No live systems, logins, or real data are connected.
- All names, properties, and figures are fictional; company and client specifics are intentionally generalized.
- Demos pull web fonts from Google, so they look best with an internet connection.
- Most demos run the actual production front-end code with the live data layer swapped for mock data. Tempo is the real React app compiled with sample data; Engine is a hand-built illustration.
